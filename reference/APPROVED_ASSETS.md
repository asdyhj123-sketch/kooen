새 이미지를 만들거나 기존 이미지를 편집할 때 아래 우선순위로 참조한다.

## 1순위: 캐릭터 정체성

- `reference/앞을 보는 귀여운 토끼 캐릭터.png`
  - 기본 얼굴, 귀, 몸통, 검정 브라탑과 전체 비율의 기준
- `assets/cupbunny/고민.png`
  - 투명 배경으로 합성할 때의 기본 포즈 기준

## 장면 참고 전용

다음 파일은 장면이나 표정 아이디어만 참고하며 캐릭터 정체성 기준으로 사용하지 않는다.

- `reference/당황하는표정.png`: 흰 상의와 효과 기호가 포함됨
- `reference/웃는표정.png`: 노트북 장면, 귀 각도와 구도가 기본형과 다름
- `reference/허리손포즈.png`: 비교 카드의 글자와 두 캐릭터가 포함됨

## 승인된 릴스 구성 참고

- `reference/history/걸을때/`: 표지 → 반복 상황 → 말풍선 결말의 5컷 흐름
- `reference/history/가큰공2/`: 상단 한 줄 문구, 중앙 장면, 4컷 공감 리스트
- `reference/history/가큰좋/`: 짧은 표지와 한 문장 장면 중심의 빠른 전개

이 세 폴더는 9:16 흰 배경, 상단 검정 손글씨, 중앙의 작은 컵토끼, 최소 효과선이라는 릴스 구성 기준으로 사용한다.

## 사용 금지

- `assets/cupbunny/_svg_사용안함/` 전체

SVG 버전은 원본 캐릭터와 형태가 달라 새 콘텐츠에 사용하지 않는다.
