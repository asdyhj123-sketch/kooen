# 기준 자료 넣는 곳

기존 ChatGPT 프로젝트의 대화와 이미지 생성 이력은 이 Codex 작업 공간에서 자동으로 보이지 않는다. 스타일을 정확히 이어가려면 아래 자료를 한 번만 옮겨야 한다.

## 권장 구조

```text
reference/
├─ approved/   최종 승인되어 실제 사용한 대표 이미지
├─ source/     컵토끼 원본, 포즈, KOOEN 로고, 브라 상품 원본
└─ rejected/   피해야 할 스타일 예시와 짧은 이유
```

`approved/`에는 최근 스타일을 가장 잘 보여주는 이미지 10~20장을 우선 넣는다. 가능하면 다음 유형을 포함한다.

- 컵토끼 기본형과 표정·포즈
- 브라사전 칠판 카드
- 공감 콘텐츠
- 캐러셀 표지·본문·마무리
- 릴스 커버

파일 이름은 내용을 알 수 있게 유지한다. 이미지 옆에 같은 이름의 `.md` 파일을 두고 “좋았던 점”을 한두 줄 적으면 생성 정확도가 더 좋아진다.

`.env`, API 키, 로그인 정보는 넣지 않는다.
