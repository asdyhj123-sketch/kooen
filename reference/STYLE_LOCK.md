# 컵토끼 스타일 잠금 기준

상태: 현재 프로젝트의 컵토끼 원본과 투명 포즈를 직접 확인한 기준. 참조 우선순위는 `reference/APPROVED_ASSETS.md`를 따른다. 추가 예시 이미지가 들어오면 카드·장면 구성 기준을 확장한다.

## 캐릭터 형태

- 큰 타원형 머리와 짧고 통통한 몸통
- 얼굴 아래 아이보리 영역은 가슴 윗부분까지 하나의 형태로 자연스럽게 이어지며, 목이나 턱을 가르는 가로 경계선을 넣지 않는다.
- 길고 둥근 귀 두 개, 귀 안쪽은 길쭉한 분홍 타원
- 별도 연출 요청이 없으면 두 귀는 접히거나 수평으로 눕지 않은 곧은 형태로 유지한다. 고개가 기울어진 장면에서는 귀 뿌리가 머리 각도와 함께 자연스럽게 회전하되 두 귀 모두 길게 펴진 상태를 유지한다.
- 작은 검정 타원 눈, 작은 분홍 코·입, 옅은 타원형 볼터치
- 손가락 묘사 없이 둥글고 단순한 손
- 짧은 다리와 작은 꼬리
- 검정색 민소매 브라탑, 하의 없음
- 기준 이미지처럼 큰 머리와 짧고 둥근 몸통, 짧은 팔다리를 유지한다. 몸통이 사람처럼 길어지지 않게 한다.
- 큰컵 정체성은 옷의 완만한 상체 실루엣으로만 표현한다. 좌우 컵이 따로 돌출되거나 깊은 넥라인, 가슴골, 꽉 끼는 신체 굴곡이 생기지 않게 한다.

## 선과 색

- 외곽선은 진회색 `#3A3A3A` 계열의 일정하고 부드러운 선
- 몸통은 아이보리 `#FEFAF5`
- 귀 안쪽과 볼은 연분홍 `#F9CEC3`
- 의상은 채도가 낮은 검정
- 흰색 또는 아주 옅은 회색 배경
- 그림자와 질감은 매우 약하게만 사용

## 표현 강도

- 귀엽고 차분한 표정
- 과장된 눈, 입, 땀방울, 눈물, 만화식 충격 효과를 쓰지 않는다.
- 신체 부위를 선정적으로 강조하지 않는다.
- 광택이 강한 3D, 사실적인 털, 사진 합성, 수채화, 복잡한 배경을 사용하지 않는다.

## 생성·편집 원칙

1. 승인된 기준 이미지가 있으면 새로 그리기보다 국소 편집을 우선한다.
2. 포즈를 바꿀 때 얼굴, 귀, 몸통 비율, 브라탑 모양, 선 굵기와 색은 고정한다.
   사연툰 안에서는 컷마다 표정, 귀 각도, 팔과 몸 방향을 달리해 장면 전환이 분명하게 보이도록 한다.
3. 한 번에 한 장씩 만들고 기준 이미지와 비교한다.
4. 다음 항목 중 하나라도 달라지면 최종 산출물에서 제외한다.
   - 귀 길이와 각도
   - 얼굴 대비 몸통 크기
   - 눈·코·볼의 위치
   - 브라탑의 넥라인과 길이
   - 큰 머리와 짧고 둥근 몸통의 비율
   - 완만하고 비선정적인 상체 실루엣
   - 외곽선의 굵기와 색
   - 몸통 아이보리 색
5. `당황하는표정.png`, `웃는표정.png`, `허리손포즈.png`는 장면 참고용이며 기본 얼굴·체형을 복제하는 기준으로 쓰지 않는다.
6. `_svg_사용안함/`의 그림은 어떤 최종 콘텐츠에도 사용하지 않는다.

## 이미지 생성 전 필수 조건

- `reference/APPROVED_ASSETS.md`에 승인 원본과 용도를 등록한다.
- 생성 프롬프트에 대표 이미지 파일을 참조로 포함한다.
- 텍스트가 필요한 카드는 캐릭터와 배경을 먼저 만든 뒤 텍스트를 별도 렌더링해 글자 변형을 막는다.
