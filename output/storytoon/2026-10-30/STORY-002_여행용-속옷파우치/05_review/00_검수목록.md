- [x] 컵토끼의 아이보리 몸·검정 브라탑·짧고 둥근 비율 유지
- [x] 컷별 표정·귀 각도·팔과 몸 방향 변화
- [x] 신체 노출이나 선정적 구도 없음
- [x] 사연 원문의 핵심 상황 유지
- [x] 마지막 컷은 고정 사연 모집 메시지
- [x] 문구는 릴스 제작 시 Jua 글꼴의 별도 영상 레이어로 처리
- [x] 릴스 미제작 상태

- 화면 문구의 말투

- 5컷 전체 승인 여부
