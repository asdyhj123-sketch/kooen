# KOOEN 주제 상태 이력

새 콘텐츠를 기획하기 전에 이 파일과 `CLAUDE.md`의 기존 게시물 목록을 함께 확인한다.

## 운영 규칙

1. `거절` 주제는 표현만 바꾸거나 유사한 소재로 다시 제안하지 않는다.
2. `이미 업로드` 주제는 후속편 요청이 없는 한 다시 제안하지 않는다.
3. `미승인` 주제는 사용자가 먼저 다시 언급하지 않는 한 새 기획 후보에서 제외한다.
4. 사용자가 주제를 거절하면 같은 작업 턴에 이 파일을 갱신한다.
5. 제목이 달라도 핵심 상황·후킹·결론이 같으면 같은 주제로 본다.
