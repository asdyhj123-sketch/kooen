# Codex 통합 콘텐츠 워크플로

목표는 사용자가 한 번 요청하면 Codex가 제작 전 과정을 수행하고, 사용자는 마지막 검수와 Instagram 업로드만 하는 것이다.

평소에는 “다음 주 콘텐츠 전체 만들어줘” 한 문장으로 시작한다. 특정 주제가 있으면 “다음 주 콘텐츠 전체 만들어줘. 핵심 주제는 와이어 위치야”처럼 한 줄만 덧붙인다.

## 1. 입력

사용자가 최소한으로 주는 정보는 기간 또는 주제 하나다. 아무 정보가 없으면 다음 게시 주간을 대상으로 기존 운영표에 맞춰 기획한다.

Codex가 자동으로 읽을 자료:

- `reference/APPROVED_ASSETS.md`와 그 안에 지정된 파일: 스타일 기준 이미지
- `reference/source/`: 로고, 캐릭터, 상품 원본
- `archive/plans/`: 이전 주간 기획
- `archive/posts/`: Apify 내보내기 또는 게시 기록
- `archive/stories/`: 접수한 사연 원문, 각색본, 제품 시사점
- `output/`: 이미 만든 결과물

## 2. 분석

1. 최근 게시물의 주제, 형식, 후킹, 반응을 정리한다.
2. 이전 기획과 비교해 주제 반복을 찾는다.
3. 정보성·공감·재가공 콘텐츠의 비율을 확인한다.
4. 실제 데이터가 없으면 그 사실을 표시하고 저장된 기록만으로 판단한다.

Apify 연결 전에는 CSV 또는 JSON 내보내기를 `archive/posts/`에 넣어 같은 분석 흐름을 사용할 수 있다.

## 3. 기획과 대본

주간 운영표에 따라 릴스 5개와 캐러셀 2개를 기본 단위로 만든다. 각 콘텐츠에는 다음을 포함한다.

- 주제와 목표
- 1초 후킹
- 컷별 초수, 화면 문구, 내레이션 또는 말풍선
- 이미지 제작 지시
- 캡션과 해시태그
- 재활용 관계와 중복 점검

## 4. 비주얼 제작

1. `reference/APPROVED_ASSETS.md`에서 주제와 가장 가까운 기준 이미지 1~3장을 고른다.
2. 기존 컵토끼 포즈와 상품 이미지를 우선 재사용한다.
3. 새 장면이 필요할 때 Codex 내장 이미지 편집·생성을 사용한다.
4. 생성 결과를 기준 이미지와 비교해 색, 선, 비율, 얼굴, 의상, 배경 밀도를 검수한다.
5. 기준에서 벗어난 이미지는 최종 묶음에 넣지 않고 다시 생성한다.

## 5. 릴스 제작

- 승인된 카드 이미지를 세로 규격에 배치한다.
- 첫 장면에 후킹을 두고 0.2초 페이드만 사용한다.
- 줌 효과와 불필요한 장식은 넣지 않는다.
- 캡션의 Markdown 강조 표시는 제거한다.

## 6. 자체 검수

다음 항목을 모두 검사한다.

- 브랜드 말투와 금지 표현
- 신체 정보의 과도한 단정 여부
- 맞춤법과 한 줄 길이
- 캐릭터 및 그래픽 일관성
- 릴스 길이와 첫 1초 후킹
- 같은 주 및 과거 콘텐츠와의 중복
- 파일 규격과 실제 재생 여부
- 캡션, 해시태그, 일정의 누락

## 7. 사용자 검수 묶음

`output/review/YYYY-MM-DD/`에 아래 구조로 저장한다.

```text
00_검수목록.md
reels/
carousels/
captions/
sources/
```

`00_검수목록.md`에는 게시 순서, 미리보기, 캡션 경로, 자체 검수 결과, 사용자가 확인할 핵심만 적는다. 사용자는 이를 확인한 뒤 직접 Instagram에 업로드한다.

사연툰은 `output/storytoon/YYYY-MM-DD/STORY-NNN_주제/` 아래에 원본, 최종 카드, 릴스, 캡션, 검수본을 나눠 보관한다. 상세 계층은 `docs/CONTENT_STRATEGY.md`를 따른다.

## 8. 수정

사용자가 수정할 항목만 말하면 해당 항목과 연관된 이미지·릴스·캡션을 함께 갱신한다. 수정되지 않은 승인 산출물은 다시 만들지 않는다.
