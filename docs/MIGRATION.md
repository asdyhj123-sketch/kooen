# 기존 KOOEN 프로젝트 이전

Codex 통합 제작을 실제로 시작하려면 기존 Windows의 `쿠엔` 프로젝트를 이 저장소로 한 번 이전한다.

## 한 번만 준비할 자료

1. 기존 `쿠엔` 폴더 전체를 ZIP으로 압축한다.
2. 압축 전에 `.env`와 API 키가 들어간 파일은 제외한다.
3. ChatGPT의 `컵컵컵` 프로젝트에서 최종 승인 이미지 10~20장을 따로 모은다.
4. 가능하면 마음에 들지 않았던 이미지 3~5장도 “피해야 할 예시”로 함께 둔다.

기존 폴더에서 특히 필요한 항목:

- `CLAUDE.md`, `AUTOMATION_SETUP.md`
- `.claude/commands/`
- `reference/`, `assets/`, `tools/`
- `output/주간/`, 기존 이미지와 릴스
- `log/게시기록.md`

이전 후 Codex가 수행할 작업:

- Claude 전용 명령을 Codex 작업 규칙으로 통합
- 카드·릴스 스크립트와 템플릿 검증
- 미구현 공감·표지·본문·마무리 템플릿 완성
- 기획 파일 선택 옵션 추가
- 기준 이미지로 스타일 고정 테스트
- Apify 입력 형식 연결 및 최근 게시물 분석
- 샘플 한 주를 전체 생성해 최종 검수 묶음 제공
