# KOOEN 브랜드 가이드

이 문서는 제공된 `HANDOFF.md`에서 현재 작업에 필요한 확정 규칙을 추린 Codex용 기준이다. 원본 프로젝트와 승인 이미지가 들어오면 실제 산출물에 맞춰 갱신한다.

## 콘텐츠의 역할

KOOEN은 큰 컵 사이즈의 브라 선택과 착용 고민을 쉽고 다정하게 설명한다. 핵심 콘텐츠는 실용적인 “브라사전”, 일상적인 공감·이야기, 브라사전을 재가공한 캐러셀이다.

콘텐츠로 큰컵 당사자의 신뢰와 실제 수요 데이터를 쌓고, 이를 향후 큰컵 속옷 브랜드와 제품 기준으로 연결한다. 각 콘텐츠는 공감 외에도 문제, 부족한 기능, 구매 기준 중 하나 이상의 시사점을 남긴다. 세부 운영 원칙은 `docs/CONTENT_STRATEGY.md`를 따른다.

## 말투

- 독자를 항상 붙여 쓴 “큰컵언니들”이라고 부른다.
- 정보는 짧고 명확하게 쓰되 훈계하거나 불안을 키우지 않는다.
- 경험담은 약점이나 실패담처럼 포장하지 않는다.
- 저장·공유를 자연스럽게 유도하고, 비슷한 경험이 있는지 묻는 문장으로 팔로우를 권한다.
- 의학적·신체적 차이를 단정하지 않는다. 필요한 경우 “일반적인 기준이에요”라고 밝힌다.

피해야 할 표현과 연출:

- “서럽다”, “눈물”, 우는 이모지, “큰컵 유저”
- 자기연민, 몸을 희화화하는 장면, 신체 접촉이나 출렁임을 강조하는 소재
- 선정적인 구도와 과도한 신체 부각
- 몽환적·화사한 무드, 과한 반짝임과 감성 필터

## 주간 운영

기본 휴식일은 수요일과 일요일이다.

| 요일 | 낮 콘텐츠 | 저녁 콘텐츠 |
|---|---|---|
| 월 | 브라사전 릴스 ① | - |
| 화 | 공감·이야기 릴스 ① | - |
| 목 | 브라사전 릴스 ② | - |
| 금 | 공감·이야기 릴스 ② | 월요일 브라사전 캐러셀 |
| 토 | 브라사전 릴스 ③ | 목요일 브라사전 캐러셀 |

- 릴스 권장 게시 시간: 13~14시
- 캐러셀 권장 게시 시간: 20시
- 릴스 길이: 7~12초
- 첫 1초: 질문 또는 결론형 후킹
- 공감 소재: 주 1개 이하
- 같은 날 릴스와 캐러셀은 서로 다른 주제를 사용한다.

## 비주얼 시스템

### 컵토끼

- 몸통: `#FEFAF5`
- 귀 안쪽·볼터치: `#F9CEC3`
- 외곽선: `#3A3A3A`
- 검정 브라탑, 하의 없음
- 큰컵을 착용하는 캐릭터라는 점이 보이도록 충분한 상체 볼륨과 둥근 브라 컵 실루엣을 유지한다. 겉옷을 입은 장면에서도 자연스러운 볼륨은 남긴다.
- 손가락을 세밀하게 그리지 않은 둥근 손
- 승인 포즈가 있으면 재생성보다 원본 재사용 또는 국소 편집을 우선한다.

### 그래픽

- 포인트 색: 라벤더·퍼플·그레이
- 카드 크기: 1254×1254
- 말풍선: 흰 배경, `#3A3A3A` 테두리, 검정 글자
- 계정 표기: `@kooen.official`
- 글꼴 기준: Jua. 기호가 없을 때 가독성 좋은 고딕 계열로 대체한다.

### 릴스

- 1080×1920, 30fps, H.264, 음악 없음이 기본
- 배경 `#F7F7F8`
- 상단에 후킹, 중앙에 카드, 하단에 회색 “KOOEN”
- 전환은 짧은 페이드만 사용하며 줌 효과는 사용하지 않는다.

## 형식별 구성

- `칠판`: 브라사전 정보 카드. 컵토끼 선생님과 어두운 칠판을 사용한다.
- `공감`: 흰 배경, 큰 문장 한 줄, 아래쪽 컵토끼 반응 포즈, 작은 시리즈명.
- `표지`: 큰 제목, 컵토끼, “브라사전”.
- `본문`: 소제목, 짧은 본문, 작은 컵토끼.
- `마무리`: 저장·팔로우 유도, KOOEN 로고.

사연툰은 각 컷의 표정, 귀 각도, 팔과 몸 방향을 다르게 구성한다. 반복되는 `사연툰 01` 배지는 넣지 않으며, 마지막 컷은 다음 사연을 기다린다는 모집 메시지로 고정한다. 캡션은 라디오 사연처럼 사연자에게 공감하고 독자의 비슷한 경험을 묻는다. 제품 정보와 기능 설명은 사연툰 화면과 캡션에 직접 넣지 않는다.
