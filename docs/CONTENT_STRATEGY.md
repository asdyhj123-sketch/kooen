# KOOEN 콘텐츠·브랜드 전략

## 장기 목표

KOOEN 콘텐츠의 최종 목표는 큰컵 당사자의 공감과 신뢰를 쌓고, 팔로워의 실제 수요를 반영한 큰컵 속옷 브랜드를 출시하는 것이다. 조회수와 팔로워 증가는 이 수요를 발견하고 검증하는 과정으로 본다.

## 콘텐츠가 남겨야 할 것

모든 브라사전, 공감툰, 사연툰은 다음 중 하나 이상의 시사점을 남긴다.

1. 큰컵 당사자가 반복해서 겪는 문제
2. 기존 제품에서 부족한 기능 또는 핏
3. 구매할 때 중요하게 보는 기준
4. 제품 개선 아이디어의 우선순위
5. 큰컵 언니들이 사용하는 실제 표현과 상황

공감이나 웃음만으로 끝나는 콘텐츠라도 캡션 또는 마지막 컷에서 자연스러운 질문을 던져 제품 수요를 수집한다. 브랜드 출시 계획을 매번 직접 홍보하지는 않으며, 답변하기 쉬운 선택지와 경험 질문을 사용한다.

## 사연툰 운영

- 사연마다 `STORY-001` 형식의 번호를 부여한다.
- 원문, 게시용 각색, 개인정보 처리 여부, 핵심 수요를 `archive/stories/`에 기록한다.
- 노출·신체 관련 사건은 선정적인 장면 없이 사물, 표정, 도식으로 표현한다.
- 마지막 컷은 사건에서 도출되는 제품 기준이나 선택 기준으로 연결한다.
- 캡션은 댓글로 기능 우선순위 또는 유사 경험을 묻는다.

## 산출물 계층

```text
output/storytoon/YYYY-MM-DD/STORY-NNN_주제/
├── 00_제작안.md
├── 01_source/        # 글자 없는 생성 원본
├── 02_cards/         # 게시 문구를 합성한 최종 컷
├── 03_reel/          # MP4와 커버 JPG
├── 04_caption/       # 게시용 캡션
├── 05_review/        # 검수 결과
├── manifest.json     # 컷 순서·길이·문구
└── STORY-NNN_검수용.zip
```
