# KOOEN 콘텐츠·브랜드 전략

## 장기 목표

KOOEN 콘텐츠의 최종 목표는 큰컵 당사자의 공감과 신뢰를 쌓고, 팔로워의 실제 수요를 반영한 큰컵 속옷 브랜드를 출시하는 것이다. 조회수와 팔로워 증가는 이 수요를 발견하고 검증하는 과정으로 본다.

## 콘텐츠가 남겨야 할 것

모든 브라사전, 공감툰, 사연툰은 다음 중 하나 이상의 시사점을 남긴다.

1. 큰컵 당사자가 반복해서 겪는 문제
2. 기존 제품에서 부족한 기능 또는 핏
3. 구매할 때 중요하게 보는 기준
4. 제품 개선 아이디어의 우선순위
5. 큰컵언니들이 사용하는 실제 표현과 상황

공감이나 웃음만으로 끝나는 콘텐츠라도 캡션 또는 마지막 컷에서 자연스러운 질문을 던져 제품 수요를 수집한다. 브랜드 출시 계획을 매번 직접 홍보하지는 않으며, 답변하기 쉬운 선택지와 경험 질문을 사용한다.

## 2026-10-27 공감 4탄 반응 반영

- `가슴 크면 공감하는 순간들 4탄`은 반응과 팔로워 증가가 좋았다.
- 운영자 확인 결과 불순한 의도로 보이는 반응도 많았다.
- 후속 모음집은 빠른 공감 구조를 유지하되 표지와 장면의 초점을 가슴 움직임보다 브라·의류·핏·제품 디테일에 둔다.
- 여성 당사자가 실제로 답할 수 있는 경험 질문으로 댓글을 유도하고, 신체 확대나 반복적인 출렁임 표현은 연속 콘텐츠에서 사용하지 않는다.

## 사연툰 운영

- 사연마다 `STORY-001` 형식의 번호를 부여한다.
- 원문, 게시용 각색, 개인정보 처리 여부, 핵심 수요를 `archive/stories/`에 기록한다.
- 노출·신체 관련 사건은 선정적인 장면 없이 사물, 표정, 도식으로 표현한다.
- 제품 시사점은 내부 기록에 남기되 사연툰 화면과 캡션에서 직접 설명하지 않는다.
- 캡션은 라디오 사연처럼 사연자의 감정과 상황에 공감하고 독자에게 비슷한 경험이 있는지 묻는다.
- 모든 사연툰의 마지막 컷은 “또 다른 사연을 기다려요”라는 모집 메시지와 댓글·DM 안내로 마무리한다.

