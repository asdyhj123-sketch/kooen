# 기존 프로젝트 상태 요약

이 문서는 2026-10-18에 제공된 `HANDOFF.md`의 구현 현황을 기록한다. 실제 파일이 이 저장소로 이전된 뒤 파일 상태와 대조해 갱신한다.

## 확인된 기존 구성

- Windows 11의 OneDrive 바탕 화면 `쿠엔` 폴더에서 운영
- Python 3.12 기반
- Pillow, OpenAI SDK, imageio-ffmpeg 사용
- Jua 글꼴 사용
- `tools/make_pose.py`: 컵토끼 포즈 생성·편집
- `tools/make_cards.py`: 카드 생성
- `tools/make_reels.py`: 릴스, 커버, 캡션 생성
- `tools/make_bra_images.py`: 상품 이미지 정리

## 구현 상태

- 칠판 카드 템플릿: 구현 완료
- 공감 카드 템플릿: 미구현
- 캐러셀 표지·본문·마무리 템플릿: 미구현
- 릴스 생성: 구현 완료, 줌 효과 제거 및 페이드만 사용
- 기획 파일 선택 옵션: 미구현, 현재 가장 최신 기획만 처리
- 말풍선: 기획안에는 있으나 템플릿과 파서에 미구현
- 첫 샘플: 2026-10-19 월요일 브라사전 릴스만 제작 완료
- 2026-10-26 주간 기획: 작성 완료, 제작 전 상태

## 컵토끼 포즈

기존 파일로 확인해야 할 포즈:

- `고민`: 원본 재사용
- `기본`: 팔만 편집한 버전, 꼬리 없음
- `설명`: 양손 허리, 둥근 손
- `실망`: 사용자가 제공한 원본 재사용
- `설명_안경`: 안경과 지시봉이 있는 원본 재사용

없는 포즈는 `OK`, `고민_안경`, `기본_안경`, `실망_안경`, `OK_안경`이다. 기존 스크립트는 안경 포즈가 없으면 `설명_안경`, `OK`가 없으면 `기본`으로 대체한다.

## 이관 후 우선 작업

1. 원본 프로젝트의 파일 누락과 사용자 변경 사항 확인
2. 대표 승인 이미지로 스타일 기준 확정
3. 기존 카드·릴스 생성 명령 재실행 및 결과 검증
4. 기획 파일 선택 옵션 추가
5. 공감, 표지, 본문, 마무리 템플릿 구현
6. 말풍선 데이터와 렌더링 지원
7. 풀컵 상품 이미지 파일명 처리
8. Apify 게시물 데이터 연결
9. 샘플 한 주 전체 생성 및 검수 묶음 완성

## 아직 확인되지 않은 사항

- 기존 브라사전 ③ “자매사이즈”의 실제 게시 여부
- `HANDOFF.md` 이후 Windows 프로젝트에서 생긴 변경 사항
- ChatGPT `컵컵컵` 프로젝트의 이미지 생성 이력과 최종 승인 이미지
- 기존 Apify Actor 또는 Task의 식별자와 데이터 형식
